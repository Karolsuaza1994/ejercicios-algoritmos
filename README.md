# Ejercicios de Algoritmos - SENA

Este repositorio contiene los talleres de desarrollo de algoritmos en Java y diagramación de flujos.

## 📁 Estructura del Proyecto

* **`Algoritmo-control-secuencial1/`**: Contiene la entrega de algoritmos secuenciales (Ejercicios 1 al 23) y el documento PDF con todos sus diagramas de flujo.
* **`Algoritmos-control-decision/`**: Contiene la entrega de estructuras de control condicionales (Ejercicios 24 al 45) junto con sus diagramas de flujo completos en formato de imagen PNG de Drawio.
